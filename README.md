# Private Messeng

Онлайн-мессенджер для небольшой закрытой группы.

## Хранилище
Проект использует PostgreSQL через `DATABASE_URL`. Для бесплатного размещения можно использовать Supabase Free.

## Запуск
1. Создайте PostgreSQL-базу.
2. Добавьте переменную окружения `DATABASE_URL`.
3. Выполните `npm install`.
4. Выполните `npm start`.

Сервер сам создаёт таблицы пользователей, сессий и сообщений при первом запуске.

Важно: база хранится отдельно от файлов сервера, поэтому перезапуск/сон web-сервиса не удаляет аккаунты и сообщения.
